# major_places.csv

Derived from GeoNames' `cities15000.txt` dump (populated places with
population >= 15000), filtered further to population >= 50000 and trimmed
to the columns used by the nearest-metro-area geocoding fallback: `name`,
`lat`, `lon`, `country_code`, `admin1_code`, `population`.

Source: https://download.geonames.org/export/dump/ (`cities15000.zip`),
licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Attribution: GeoNames (https://www.geonames.org/).
